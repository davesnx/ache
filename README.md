# ache

ache is an HTTP/1.1 library for OCaml, with runtimes for Eio (`ache-eio`) and
Lwt (`ache-lwt`). It is a fork of
[httpun](https://github.com/anmonteiro/httpun), which is itself a fork of
[httpaf](https://github.com/inhabitedtype/httpaf). Status: work in progress;
the API can change.

`vendor/faraday` is an unmodified copy of
[Faraday](https://github.com/inhabitedtype/faraday) 0.8.2, under its own
BSD-3-Clause license in `vendor/faraday/LICENSE`.
