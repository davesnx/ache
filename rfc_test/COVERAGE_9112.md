# RFC 9112 coverage

Source: <https://www.rfc-editor.org/rfc/rfc9112.txt>. One row per sentence of RFC 9112 §2–§11
that contains a BCP 14 keyword, plus rows with keyword `DEF` for definitions (ABNF, message
body length rules, persistence rules, security considerations) that a parser or generator
must follow although the sentence has no keyword. `Ref` is the section and the sentence's
position in it; `#D` rows are definitions.

Test names are in `rfc_test/test_9112_*.ml`; a name followed by "(RFC 9110 suite)" is in
`rfc_test/test_s*.ml`. Every listed test passes; see `KNOWN_FAILURES_9112.md`.
